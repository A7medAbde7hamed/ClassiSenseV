Connect a test Firebase workspace to see live readings.

Firebase setup guide
  1. Use a dedicated test Firebase project with Firestore enabled.
  2. Add FIREBASE_SERVICE_ACCOUNT_JSON and DASHBOARD_PASSWORD as server-only Vercel environment variables, then redeploy.
  3. Use the same test project credentials on the local tracking computer. Run the tracker with the new firmware uploaded.

Credentials stay on the server. No service-account key belongs in the browser or this repository.
